Osobní asistent v3.1.1 – nové VAPID klíče

Zachovává aplikaci v3.1. Mění veřejný VAPID klíč v index.html a functions/api/push-test.js.

1. Nahrajte všechny soubory ZIP do GitHub repozitáře včetně functions.
2. V Cloudflare Pages nastavte Secret VAPID_PRIVATE_KEY podle SAMOSTATNÉHO souboru s privátním klíčem.
3. Na iPhonu otevřete aplikaci ikonou a znovu stiskněte Zaregistrovat iPhone pro push.
4. Pak stiskněte Poslat test ze serveru.

Soukromý klíč NIKDY nenahrávejte na GitHub.
